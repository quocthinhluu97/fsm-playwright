 Model based testing with Playwright

Model based testing is using State machine library XState, Playwright and the UI interactions can be achieved via any browser

## Intro
> Note: This is a demonstration repository focused on showcasing model-based testing concepts. The code structure and organization can be improved for production use cases. Feel free to refactor and enhance the implementation based on your project's needs and best practices.

## Installation
Install the dependencies and run playwright tests

```sh
cd fsm-playwright
npm install
npx playwright test
```
